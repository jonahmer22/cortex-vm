All addresses are 64-bit word addresses. Each word is 8 bytes.

Assembler Directives

DirectiveDescription
.dataBegin data section - must appear after all code, at end of file

Inside .data: integers, floats, char literals, and quoted strings are accepted. Each value occupies one 64-bit word; strings are null-terminated word arrays. Execution begins at the first instruction in the file.

F Extension - 64-bit IEEE 754 Floats

Floats share the same register file (r0-r63). Float immediates are 64-bit IEEE 754 bit patterns. Requires EXT_FLOAT flag set in binary header.

Syscall Quick Reference

Set a13 to the syscall number, populate args in a0-a12, then execute syscall. Return values appear in a0.
